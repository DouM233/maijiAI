# 麦吉AI 前端原型

这是“麦吉AI 企业智能工作台”的第一版前端原型。

## 打开方式

直接用浏览器打开 `index.html`。

也可以在 PowerShell 中运行：

```powershell
.\dev.ps1
```

开发服务器默认使用 `http://127.0.0.1:5175/`。

## 已包含

- 钉钉登录入口，点击后进入假用户工作台
- 类 Gemini 的浅蓝白色主界面
- 公司 IP 形象展示
- 左侧导航、历史记录、今日额度展示
- 中央问候语和对话输入框
- 快速 / 思考 / Pro 模型下拉切换
- 管理工具、电商工具卡片区
- 四个核心专家卡片：
  - 爆款裂变分析AI教练
  - 天猫竞争策略教练
  - 小红书千帆投放专家
  - 个人访谈官
- 新增结构化专家：
  - 电商管理落地顾问
- 专家配置已拆成 Profile / Constraints / Goals / Workflow
- 创建专家页面，字段采用中英双语
- 创建页支持右侧实时预览和临时保存成专家卡片
- 自建专家保存到浏览器 localStorage，刷新后仍保留
- 后台管理页面可查看新增专家和系统预置专家
- 知识库挂载功能收敛到后台管理侧，用户面板不提供知识库挂载入口
- 后台知识库页面，支持文档上传占位、RAG 状态展示和专家挂载设置
- 后台审计与用量模块，包含部门结构、Token 消耗、专家调用排行和风险会话
- 风险会话直接落到具体员工姓名、岗位、部门小组和风险类型
- 用户与部门管理模块，展示员工部门、角色、额度和可见专家数量
- 权限额度配置改为先选部门，再选部门内员工
- 后台管理各模块支持展开和收起
- 点击专家卡片后弹出上下文摘要确认窗
- 确认后进入专家模式，并锁定模型选择
- 发送消息后进入对话流，展示用户消息和模拟 AI 回复
- 用户消息靠右，AI 回复靠左
- AI 回复支持逐字生成效果

## 后续接入预留

后续从前端原型升级到真实 MVP 时，建议把 `api.bltcy.ai` 中转站的 Key 放在服务端环境变量中，不要写进前端代码。

建议的下一阶段技术栈：

- Next.js
- Tailwind CSS
- Supabase Auth / 数据库
- Vercel AI SDK 或兼容 OpenAI 格式的服务端请求封装

专家 MVP 架构说明见 `docs/expert-mvp-architecture.md`。

完整项目交接文档见 `docs/project-handoff.md`。
